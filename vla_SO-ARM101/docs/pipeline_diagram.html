Current real pipeline REAL

How the reference flow (LEROBOT_GUIDE.md — Windows/RTX4090) captures data today, without ROS2.
Current reality of the real path:
  • Runs on Windows + RTX4090 (per LEROBOT_GUIDE.md).
  • USB serial to both arms; cameras enumerated via OpenCV index / RealSense serial.
  • Does not touch ROS2 at all today. Same dataset format as the sim side — so schemas match for co-training.

Target: unified sim + real via ROS2 TARGET

What's missing before "full dataset" is real GAPS

# Gap Why it matters Status
1 Real Gazebo topics wired into the smoke script Moves us from "synthetic" to "actually sim-recorded" — confirms camera + joint timing align at 30 fps. missing

6 Second camera (top view) Colleague's real flow records wrist + top. Our sim only has the wrist-mounted camera. Either add a top-view SDF camera or agree on single-camera co-training. single-cam
7 Real side on ROS2 Real SO-101 currently uses USB/COM ports, not ROS2 topics. For the unified target, need usb_cam + realsense2_camera nodes (or keep the USB path and accept two code paths). optional
8 compute_stats pass + HF-hub push Dataset stats are required for training normalization. Push needed for co-training with colleague's real dataset. missing
